## Bugs detectados

### [BUG] `LooksMathLike` definida pero nunca llamada — hints de error para texto arbitrario

- **Fichero**: `Yottacast.Core/Search/Calculator/CalculatorSearch.cs:68`
- **Qué ocurre**: el método `LooksMathLike` tiene docstring explicando su propósito ("avoid showing error hints for random non-math text like 'safari'"), pero no se invoca desde el bloque que establece `LastHint`. Cualquier query que contenga `to` y algún identificador (ej. `"safari to km"`) puede producir un hint `UnknownSymbol` en la UI aunque no sea una expresión matemática.
- **Impacto**: hints de error confusos para texto no matemático.
- **Fix sugerido**: añadir `&& LooksMathLike(q)` a la condición del bloque `LastHint`, o eliminar `LooksMathLike` y documentar que el comportamiento actual (hints incondicionales) es intencional.

### [BUG] Auto-conversión a `DefaultCurrency` no excluye el caso `unitFrom == DefaultCurrency`

- **Fichero**: `Yottacast.Core/Search/Calculator/MathJsEngine.cs` (lógica de auto-conversión)
- **Qué ocurre**: si el usuario escribe `10 EUR` y `DefaultCurrency = "EUR"`, el engine añade `" to EUR"` produciendo `"10 EUR to EUR"`. math.js lo evalúa como `10 EUR`, que es idéntico a la query trimmeada. `CalculatorSearch.Search()` descarta resultados iguales a la query, por lo que `10 EUR` no produce ningún resultado en la UI.
- **Impacto**: `10 EUR` (y cualquier divisa que coincida con `DefaultCurrency`) no muestra resultado.
- **Fix sugerido**: añadir `&& !string.Equals(unitFrom, DefaultCurrency, StringComparison.OrdinalIgnoreCase)` a la condición de auto-conversión.

### [BUG menor] Hardcoding dual de `"USD"` como divisa base

- **Fichero**: `Yottacast.Core/Search/Calculator/MathJsEngine.cs` (skip de registro de USD)
- **Qué ocurre**: el skip `if currency == "USD" continue` y la constante `DefaultCurrency = "EUR"` están desacoplados. Si `DefaultCurrency` cambia a otra divisa, USD sigue siendo la base hardcodeada del engine sin relación explícita.
- **Impacto**: bajo con la configuración actual. Fragilidad si se refactoriza la divisa base.
- **Fix sugerido**: extraer una constante `BaseCurrency = "USD"` y usarla en el skip en lugar del literal.
