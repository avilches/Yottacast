## Bugs detectados

### [BUG] `LooksMathLike` definida pero nunca llamada

- **Fichero**: `Yottacast.Core/Search/Calculator/CalculatorSearch.cs:68`
- **Qué ocurre**: `LooksMathLike()` está definida como método privado y el docstring de la clase menciona que se usa para filtrar cuándo mostrar el item de error ("when the query looks math-like"). Sin embargo, `Search()` muestra `LastHint` para cualquier error accionable (`WrongUnitCasing`, `UnknownSymbol`, `IncompatibleUnits`) **independientemente** del resultado de `LooksMathLike`. El método es dead code.
- **Impacto**: Para queries como `safari to km` (sin dígitos ni operadores), si math.js devuelve `UnknownSymbol`, se mostraría el hint de error aunque la query no "parezca" matemática. Puede producir hints confusos para texto aleatorio que contiene nombres de unidades.
- **Fix sugerido**: Opción A — añadir `&& LooksMathLike(q)` a la condición del bloque de `ErrorKind` en `Search()`. Opción B — eliminar `LooksMathLike` si el comportamiento actual (mostrar hint siempre) es intencional.
